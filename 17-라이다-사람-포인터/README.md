# 17. 라이다 사람 포인터 (LiDAR Human Pointer)

YDLIDAR(2D LiDAR)로 공간 안의 사람을 실시간으로 인식하고, 그 위치를 Unity 화면의 **포인터(마우스 커서 역할)** 로 변환하는 입력 모듈입니다.
대형 화면에서 사람이 직접 움직여 퀴즈 정답을 고르는 체험 전시(LiDAR 퀴즈 체험)의 센서 입력 부분을 테스트하던 프로젝트입니다.

> 이 폴더는 **센서 입력 모듈만** 담고 있으며, 퀴즈 화면·콘텐츠 로직은 포함하지 않습니다.

## 처리 흐름

```
LiDAR (Serial)
   │  별도 스레드에서 스캔 수신 (CLidarSerialController)
   ▼
ConcurrentQueue<LaserScan>        ← 최신 스캔 1개만 유지
   │  메인 스레드 Update()에서 꺼냄 (CLidarManager)
   ▼
극좌표 → Unity 월드 좌표 변환 + 영역 필터링
   ▼
클러스터링으로 사람 후보 선택 (HumanTacker)
   ▼
월드 좌표 → UI 화면 좌표 변환 (Pointer)
```

## 핵심 설계

| 항목 | 내용 |
|---|---|
| 스레드 분리 | 센서 수신은 백그라운드 스레드, Unity 오브젝트 접근은 메인 스레드에서만 수행 |
| 지연 방지 | 큐에 쌓인 이전 스캔은 버리고 최신 1개만 사용해 화면이 센서보다 늦어지지 않게 함 |
| 영역 필터링 | 설정한 사각 영역 밖의 포인트는 제외해 벽·주변 물체 오인식 방지 |
| 사람 인식 | 가까운 포인트끼리 묶어 클러스터를 만들고, 포인트 수가 가장 많은 클러스터를 사람으로 판단 |
| 추적 유지 | 인식이 일시적으로 끊겨도 `lostFrame`(기본 20프레임) 동안 마지막 위치를 유지해 포인터 떨림·깜빡임 감소 |
| 좌표 변환 | LiDAR 거리·각도를 Unity 좌표로 바꾸고, 다시 Canvas 크기에 맞춰 화면 좌표로 매핑 |
| 설정 분리 | 포트, 최소·최대 감지 거리를 `설정(StreamingAssets)/Math.json`으로 분리해 현장에서 빌드 없이 조정 |
| 디버그 | 인식된 포인트를 오브젝트 풀링으로 화면에 표시 |

## 파일 구성

```
스크립트/
  라이다/
    CLidarManager.cs           스캔 수신 큐 처리, 좌표 변환, 영역 필터링, 디버그 포인트 표시
    CLidarSerialController.cs  센서 설정·구동 및 스캔 수신 스레드
    CLidarSensor.cs            센서 위치 기준 Transform용 컴포넌트
  공통/
    HumanTacker.cs             클러스터링 기반 사람 위치 추적
    Pointer.cs                 월드 좌표 → UI 화면 좌표 변환
    JsonManager.cs             Math.json 로드
설정(StreamingAssets)/
  Math.json                    포트·감지 거리 설정
```

## 환경

- Unity 2022.3.62f2
- 센서: YDLIDAR (시리얼 연결)

## 제외한 항목

- **YDLIDAR 제조사 SDK 및 SWIG 자동 생성 C# 래퍼**: 제 코드가 아니므로 포함하지 않았습니다. 이 저장소만으로는 빌드할 수 없으며, 제조사 SDK를 별도로 받아 `YDLidar` 스크립트 폴더(`스크립트/` 아래)로 추가해야 합니다.
- 씬, 프리팹, 머티리얼 등 Unity 에셋
